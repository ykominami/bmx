# 内部仕様書 — インデックス

`js/**/*` から生成したクラス別内部仕様書の一覧。

| ファイル | クラス | 概要 |
|---------|--------|------|
| [addfolder.md](addfolder.md) | `AddFolder` | ブックマークフォルダの追加および管理を担うクラス。 |
| [data.md](data.md) | `Data` | ブックマークデータの一括管理および高速検索（ハッシュマップによる管理）を行うクラス。 |
| [global.md](global.md) | —（モジュール） | 拡張機能のグローバルな設定情報およびローカルストレージとのデータ送受信を管理するレガシーモジュール。 |
| [globalx.md](globalx.md) | `Globalx` | グローバル設定とストレージ管理を提供する静的クラス。 |
| [item.md](item.md) | `Item` | ブックマークツリー内の各ノード（ブックマークアイテムまたはフォルダ）を表現し、分類するクラス。 |
| [itemgroup.md](itemgroup.md) | `ItemGroup` | ブックマークアイテムグループを管理・構築するクラス。 |
| [movegroup.md](movegroup.md) | `Movergroup` | ブックマークの自動移動ルール（ホスト名 -> 移動先フォルダ階層パス）を管理するクラス。 |
| [mover.md](mover.md) | `Mover` | 特定の移動先階層へのブックマーク移動処理を行うクラス。 |
| [popupx.md](popupx.md) | `PopupManager` | ポップアップ UI 全体を初期化・制御・イベントハンドリングするクラス。 |
| [util.md](util.md) | `Util` | UI要素の動的生成やURLパースなど、汎用ユーティリティ関数を提供する静的クラス。 |
