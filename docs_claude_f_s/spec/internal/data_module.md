# data — モジュール内部仕様書

**ファイル**: `js/data.js`

## 概要

`Data` クラス（[[data]]）のシングルトンインスタンスを生成し、他モジュールから共有データストアとして参照可能にするためのモジュールレベル定義。

---

## モジュールレベル定数・型

| 変数名 | 値/型 | 用途 |
|--------|-------|------|
| `data` | `Data` のインスタンス（`const`） | アプリケーション全体で共有されるブックマークデータストアのシングルトン。`export { data }` で公開され、ほぼ全モジュールがこれをインポートして参照する。 |

---

## 設計上の注意

- シングルトンはモジュールスコープの `const` により実現されており、明示的なリセット/破棄手段がない。単体テストでのモック差し替えが難しい設計。
